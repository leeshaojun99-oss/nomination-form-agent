# Nomination Form Agent

A small browser app that fills in the Great Eastern **Appointment / Change of Nominee(s) / Trustee(s)** form (version NBZ-FNOMI-V07-082025) for you, box by box.

**Privacy:** everything runs inside your own browser. Policy PDFs, customer details and the filled forms are never uploaded or sent anywhere. This page contains no customer data and no copy of the form itself.

## How to use

1. Open the web page. The first time, choose your blank **Nomination Form.pdf**. The app remembers it in that browser.
2. **Part 1:** upload the customer's policy PDF (the ePartner Policy Detail page saved with Ctrl+P → Save as PDF). The policy no., name, NRIC and Muslim / Non-Muslim fill in automatically. Check them.
3. **Part 2:** paste the WhatsApp nominee details. The table fills itself.
4. **Part 3:** set the date signed and the witness.
5. **Part 4:** add trustees (only for a trust policy).
6. **Part 5:** add consent persons (only if needed).
7. Click **Add customer → check**, review the check results, preview the form, approve, and download the PDF.

Signatures, consent signature dates and submission stay manual. Always check the filled form against the policy records before the customer signs.

## Notes

- The app needs internet to load its helper libraries (pdf-lib, pdf.js, SheetJS, Tesseract OCR) from public CDNs.
- Box positions are measured for form version **NBZ-FNOMI-V07-082025**. Don't use the app with a different version.
- This is a personal productivity tool. It is not an official Great Eastern product.
